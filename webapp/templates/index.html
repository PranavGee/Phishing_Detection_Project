How it decides

Nine structural properties are read straight from the address bar — no page content, no cookies, no browsing history.

  • length_url total length of the address
  • length_hostname length of the domain part
  • ip raw IP address or long hex token
  • nb_dots number of .
  • nb_hyphens number of -
  • nb_at number of @
  • nb_qm number of ?
  • nb_and number of &
  • nb_or number of |
